# 锂金属晶界结构与SOAP方法

研究目标：量化晶界结构无序，检验其与亚稳状态、变形机制和临界剪切强度的关联。

## 当前研究

- **已完成**：扩尺寸Li双晶的高温NPT、淬火和10 K零压保持，阶段一原目标验收通过；Ni SOAP完成240组参数扫描及径向补充诊断。
- **当前卡点**：SOAP径向收敛和部分高阶基函数的数值可靠性，尚未确定最终参数。
- **下一步**：先解决表征方法，再从已有Li构型开展结构比较和剪切响应研究。
