# 标准协议：Li Σ5 2×2，淬火后 aniso 松弛

协议标识：`li-sigma5-2x2-aniso-10k`。2026-10-31 确定为现行流程；这表示工作流已选定，不表示历史构型已经通过新的验收程序。

## 模型与上游处理

| 项目 | 现行设置 |
|---|---|
| 模型 | BCC Li Σ5(310)[001]，14400 原子，两个周期晶界 |
| 构造 | 镜像双晶；K=6、J=6、L=20；a=3.506186475312 Å |
| 势函数 | SNAP_ZuoChenLi_2019_Li__MO_732106099012_000 |
| 初始弛豫 | 0 K CG，box/relax aniso 0 bar；检查原子力收敛 |

| 淬火 | 363 → 10 K，10 K/ps，共 35.3 ps；iso 0 bar，Pdamp=1 ps |

| 随机种子 | 12345；独立复验时记录其他种子与来源 |

几何生成算法沿用已验证的镜像构造；现行默认参数统一为 14400 原子。上游处理输入由[阶段一脚本](../history/experiments/phase1_2026-09/Li_Sigma5_310_2x2_阶段一零压结果_2026-09-03/6_结构分析)移植，改为显式输入输出路径。

直接输入淬火 restart 时，应核对原子数、温度、模型、退火和淬火协议，并保留来源；10 月对照实验与阶段一来自不同运行记录，不能把两者的阶段文件拼成同一条原始轨迹。

## 淬火后 aniso 松弛

- 在 10 K、目标正应力 0 bar 下使用 `fix npt ... aniso`，三个盒长分别调整。
- Tdamp=0.1 ps，Pdamp=0.1 ps，默认先运行 5 ps。Pdamp 沿用[10 月对照](../history/experiments/barostat_2026-10/README.md)的 aniso_fast 设置，尚未完成阻尼敏感性优化。
- 每 200 步记录热力学数据及轨迹，每 1000 步写 checkpoint。
- 记录六个应力分量、盒长、温度、势能。aniso 不调节剪切应力，剪切分量仍需检查。
- 保留速度场，输出 `candidate.data` 和 `candidate.restart`，不在此时命名为标准起点。

## 三项审查

| 检查项 | 必须判断与记录的内容 |
|---|---|
| 应力 | Pxx/Pyy/Pzz 是否接近目标并且无持续漂移；Pxy/Pxz/Pyz 是否存在不可忽略的残余；温度是否稳定在 10 K 附近 |
| 盒长 | 后段分块均值是否稳定；是否仍有持续收缩/膨胀；记录相对淬火态的三个方向应变 |
| 结构 | 检查多个后段快照；晶粒内部保持 BCC；取向与晶界几何保持目标关系；无整体熔化、异常空洞或晶界持续重构/迁移；比较晶界区域与晶粒内部，记录所用区域和判据 |

工具生成后半段样本统计、分块均值差与盒长相对漂移，明确记录实际样本数和时间窗。样本标准差表示波动，不能当成均值误差；短轨迹的采样相关性需另行评估。

**数值稳定性阈值尚未冻结。** 审查者应在每项 `criterion_and_result` 中明确写出所用容差、观察窗口、结果与判断依据，并引用本次运行目录内的证据文件。阈值应在比较多个构型前统一，不能为单个结果临时放宽。无法判断时保持未通过状态，延长模拟或补做分析；5 ps 和正常退出本身都不是验收判据。

结构无序不等于热力学亚稳程度；约 1% 的盒长变化也不能单独作为 Σ5 身份丢失的证据。采用同一协议处理后续剪切比较的所有构型，并明确其边界条件。

## 保存与追溯

`checkpoint.py inspect` 将候选结构、restart、日志、轨迹、参数和源文件绑定到哈希清单。三项审查通过且明确批准后，`checkpoint.py save` 才生成：

- `standard_start.data`、`standard_start.restart`；
- `review.json`、`candidate_manifest.json`；
- `evidence/` 内的源文件、日志、轨迹及审查材料；
- `STANDARD_START.json`，记录保存包的校验和与审查者。

候选原始证据在检查后改变会阻止保存。已有输出目录不会覆盖。历史的 3600 原子模型、iso 保持态、x-only 和 aniso 对照态留在 `history/`，用于溯源与验证，不自动继承标准起点资格。

本次整理验证了代码和流程约束；未重跑整条 MD，也未把任何历史构型标记为已验收标准起点。
