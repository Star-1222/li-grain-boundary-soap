# Stage 06：最终方法审计与独立性检查

报告类型：确定性与待讨论事项

整理日期：2026-09-25

## 1. 本阶段范围

本阶段审计方向与辅助标量关联能否在以下控制下保留：

- 匹配 D；
- 物理描述符；
- 状态标签；
- 分组交叉验证；
- 极端值排除。

## 2. 可以确定

### 2.1 匹配分析的实际结果

在容差 0.10 的当前实现中：

- stable-stable 原始 Spearman 为 0.2591。
- metastable-metastable 原始 Spearman 为 0.6045。
- stable-metastable 原始 Spearman 为 0.7530。
- all 原始 Spearman 为 0.8317。

控制平均 D、`|D_i-D_j|`、CN、键应变、体积、CSP 和状态后：

- stable-stable partial Spearman 为 0.0519。
- metastable-metastable partial Spearman 为 0.1823。
- stable-metastable partial Spearman 为 0.0907。
- all partial Spearman 为 0.2058。

### 2.2 分组 CV 的辅助标量模型

当前实现的能量模型 R2：

- 仅 D：0.0393。
- D + 物理描述符：0.9869。
- D + 物理描述符 + 方向：0.9886。
- D + 方向：0.7497。

当前实现的状态分类 ROC-AUC：

- 仅 D：0.6062。
- 仅物理描述符：0.6842。
- D + 物理描述符：0.7029。
- D + 方向：0.5767。
- D + 物理描述符 + 方向：0.6890。

### 2.3 稳健性排除

- 排除极端 CSP 后，匹配 Spearman 约为 0.8313。
- 排除极端体积后，约为 0.8320。
- 排除极端能量后，约为 0.8316。
- 原始匹配关联对当前极端值排除规则稳定。

### 2.4 本次补充核对

- 改成留一结构后，`D + 物理描述符` 的测试集 R2 约为 0.971-0.995。
- 加入方向项没有显示稳定的额外增益。
- 因此当前数据支持物理描述符是强基线，不支持方向提供稳定的大幅预测增量。

## 3. 不能确定

- `interface_id` 分组不是独立 GB 分组。
- 同一结构中的两个界面共享构型、势函数和生成条件。
- 当前 PCA 在全部数据上拟合后再进入 CV，存在预变换泄漏。
- 现有分组 CV 在测试时仍使用同一构型的另一个界面训练。
- 原子级 bootstrap 和匹配对的重复使用会高估有效样本量。
- 当前配对生成按排序和上限截断，不是随机代表抽样。
- 方向 PC 的物理含义没有独立验证。
- 物理描述符模型在新 GB 构型上的泛化能力未知。
- 状态分类在只有两个结构时无法做真正的新状态验证。
- 现有数据不能证明方向与辅助标量存在因果或普适关系。
- 现有数据不能确定 stable 或 metastable 的无序度排序。

## 4. 需要讨论

| 问题 | 对结论的影响 | 建议处理 |
|---|---|---|
| 独立单元 | 当前 CV 不是新 GB 验证 | 按 GB 构型做 leave-one-GB-out |
| 预处理泄漏 | PCA 使用测试数据 | 每折内拟合 PCA 和标准化 |
| 配对依赖 | 置信区间和置换结果被高估 | 构型级 bootstrap 和分层 permutation |
| 方向增量 | 物理描述符已解释大部分辅助标量 | 只报告消融差值，不做强物理命名 |
| 模型选择 | 线性模型结果不能覆盖所有误差结构 | 保留物理解释性基线，避免复杂模型过度解释 |
| 数据规模 | 只有两个 CFG 构型 | 增加多个独立 stable/metastable GB 后再检验泛化 |

## 5. 当前处置

- Stage 6 可以支持“方向信号在匹配 D 下具有描述性关联”。
- Stage 6 不能支持“方向提供独立于物理描述符的大幅预测增益”。
- Stage 6 不能支持“方向导致辅助标量变化”或“适用于所有 GB”。
- 所有结论只限当前两个 Ni 构型，用于方法可行性判断。
