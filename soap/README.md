## 既有六阶段归档

归档整理日期：2026-09-25

重跑入口：[工作流与执行顺序](../maintenance/docs/WORKFLOWS.md)。先运行 `python maintenance/tools/prepare_soap_workspace.py --dest runs/ni-soap-001`（仓库根目录），准备同目录脚本与共享输出的独立副本。

本项目的主要目标是探索可迁移的 SOAP 方法。它不是势函数或能量来源审计，后续工作重点是 SOAP 参数、距离定义、体相参考、LAE 稳定性、方向表示和独立验证。

本目录按 Ni SOAP 六阶段流程归档，每个 Stage 文件夹内含：

- `01_报告/`：覆盖该阶段的方法学报告；
- `02_脚本/`：该阶段使用的 Python 脚本与输入文件；
- `03_输出/`：该阶段生成的数据、图表、XYZ 和报告草稿。
