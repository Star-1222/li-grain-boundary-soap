# SOAP方法研究

目标是寻找可靠的局域结构差异表征，并检验与晶界状态及力学响应的关联。当前卡点是径向表示的数值可靠性与收敛，尚未确定最终参数。

- **[当前工作与复现准备入口](current/README.md)**：准备独立参数研究副本，不覆盖原始结果。
- **[已完成实验](experiments/README.md)**：中期扫描、分层审计、径向补充诊断，分别保留统计口径。
- **[历史六阶段归档](history/README.md)**：旧脚本、输入、报告和结果，仅按需查阅。

动态进度统一看[研究状态](../maintenance/docs/RESEARCH_STATUS.md)。SOAP距离目前是相对体相参考的结构差异候选指标，尚未验证为亚稳程度或剪切强度的直接度量。
