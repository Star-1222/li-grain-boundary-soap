# Stage 05：物理描述符对照与 SOAP 方向

报告类型：确定性与待讨论事项

整理日期：2026-09-25

## 1. 本阶段范围

本阶段包含 Stage 5A 和 Stage 5B：

- 用 CN、键应变、Voronoi 体积和 CSP 对照残差辅助标量；
- 检查空间组织和 patchiness；
- 构造 SOAP 位移方向；
- 在匹配 D 的条件下比较方向距离和能量差。

## 2. 可以确定

### 2.1 物理描述符

- 第一近邻截断约为 2.9924 Å。
- 体相第一近邻距离参考约为 2.4793 Å。
- 清洁体相 Voronoi 参考体积约为 10.7757 Å3。
- 已计算 CN、近邻距离均值/标准差/CV、键应变、CSP、Voronoi 体积和超额体积。

### 2.2 残差辅助标量关系

- 界面平均近邻距离与残差辅助标量的 Spearman 为 -0.503。
- 有符号键应变与残差辅助标量的 Spearman 为 -0.503。
- CN 与残差辅助标量的 Spearman 为 -0.392。
- Voronoi 超额体积与残差辅助标量的 Spearman 为 -0.360。
- CSP 与残差辅助标量的 Spearman 为 0.202。
- 物理描述符解释部分辅助标量，但仍存在较大散布。

### 2.3 空间组织

- 已生成 stable 和 metastable 各自的 D、残差辅助标量和键应变空间图。
- 已计算面内自相关和 top-10% 原子 patchiness。
- top-10% 残差辅助标量原子的近邻距离约为 0.005-0.026 Å。
- 这些原子的 3 Å 内共现比例约为 1%-4%。
- 在当前尺度下，残差热点没有表现为强聚块。

### 2.4 方向定义与结果

- 当前方向由 `delta_s = s_i - mean_kNN_bulk` 和归一化方向 `u` 构造。
- 匹配 D 的原始全配对 Spearman 为 0.8317。
- 置换零模型均值约为 0.0874。
- stable-stable 的原始 Spearman 约为 0.2591。
- metastable-metastable 的原始 Spearman 约为 0.6045。
- stable-metastable 的原始 Spearman 约为 0.7530。
- metastable 态内平均方向余弦约为 0.5235。
- stable 态内平均方向余弦约为 0.6259。
- 方向 PCA 是描述性投影，PC1 和 PC2 分别解释约 44.6% 和 36.7%。

## 3. 不能确定

- 物理描述符的截断和 Voronoi 结果是否对参数稳健，未完全确认。
- 残差辅助标量按 D 分箱定义是否会过度控制或引入分箱伪影，未验证。
- patchiness 结论是否会在不同空间尺度和多个 GB 上保留，未确认。
- 方向使用的原始位移仍混入 SOAP 范数变化。
- 在归一化 SOAP 空间重算方向后，结果是否保留，未验证。
- PCA 在全部数据上拟合，不能作为独立验证的一部分。
- 匹配对由重复原子组成，0.83 不是独立样本相关系数。
- 匹配对的截断上限和选择顺序可能偏向特定 D 区域。
- 方向与物理描述符重叠多少、剩余多少，未通过严格消融确认。
- 方向与辅助标量之间的因果关系不是本项目目标，当前数据也不能证明。

## 4. 需要讨论

| 问题 | 主要风险 | 建议处理 |
|---|---|---|
| 方向定义 | 当前方向混入幅度和密度 | 在归一化 SOAP 空间重算 `delta_u` |
| PCA 拟合 | 全数据 PCA 泄漏到 CV | 每个训练折重新拟合 PCA |
| 匹配对依赖 | 同一原子重复进入大量配对 | 构型级 bootstrap 和区块 permutation |
| 物理描述符基线 | 方向可能只是描述符的重新组合 | 做消融、正交化和外部构型测试 |
| 空间结论 | 两个 GB 不足以支持普适空间规律 | 只保留当前结构的描述性说明 |
| 状态差异 | stable-stable 方向关联很弱 | 不声称方向对所有状态一致 |

## 5. 当前处置

- 物理描述符应作为后续任何辅助标量或方向模型的必要基线。
- 当前方向结果仅作为描述性线索。
- 正式方向分析必须在归一化空间、匹配归一化距离和折内 PCA 下重做。
- 不声称方向决定辅助标量、方向是通用序参量或 metastable 更无序。
