# Stage 04：连续体相偏离与辅助标量测试

报告类型：确定性与待讨论事项

整理日期：2026-09-25

## 1. 本阶段范围

本阶段包含 Stage 4A 和 Stage 4B：

- 从清洁体相参考构造连续体相偏离坐标 D；
- 检查 k、参考和 bootstrap 稳健性；
- 用局域 `c_PEATOM` 测试 D 是否携带任何辅助标量信息；
- 检查分箱趋势、共同支撑和 PCA。

## 2. 可以确定

### 2.1 体相参考

- 主参考条件为 `region=bulk`、`PTM=1`、`CNA=1`。
- 参考筛选还使用了每个结构 PEATOM 的 `Q1-3IQR` 范围。
- pooled 清洁体相参考为 964 个原子。
- stable 参考为 476 个原子。
- metastable 参考为 488 个原子。
- 参考原子在当前实现中执行 leave-one-out。

### 2.2 连续 D

- 主指标为 `D(k=10)`，即到 10 个最近清洁体相参考原子的平均原始 SOAP 距离。
- `k=5/10/20` 之间的相关系数高于 0.99。
- pooled 参考与分状态参考的排序相关性约为 0.999。
- stable 界面 D 中位数约为 6.7437。
- metastable 界面 D 中位数约为 5.9719。
- stable 减 metastable 的界面中位数差约为 0.772。
- 该差值的 95% bootstrap 区间为 `-0.129-1.601`，包含零。
- 两个状态的体相 D 中位数约为 0.03。

### 2.3 D 的数值组成

- 当前 D 使用原始未归一化 SOAP 距离。
- 界面之间的距离约有 42%-46% 的平方贡献来自 SOAP 范数差。
- D 的数值稳健不能证明它是纯结构形状坐标。

### 2.4 辅助标量关联

- pooled 清洁体相 PEATOM 基线约为 `-4.450650 eV/atom`。
- 全体原子的 Pearson 为 0.449，Spearman 为 0.510。
- 仅界面的 Pearson 为 0.258，Spearman 为 0.277。
- stable 界面 Spearman 为 0.3265。
- metastable 界面 Spearman 为 0.2689。
- 分箱趋势并非单调，在高 D 尾部出现下降。

## 3. 不能确定

- D 是否代表热力学无序度，未确认。
- D 的原始距离幅值是否主要由局部密度或配位数控制，未分解确认。
- 用 PEATOM 做参考离群过滤是否会人为影响 D 与辅助标量的关联，未做独立筛选对照。
- pooled 参考与分状态参考哪个更适合跨状态比较，未决定。
- 主指标是否应采用 `d_norm`，未决定。
- `k=10` 是否是物理解，还是只是数值平滑选择，未确认。
- stable 与 metastable 的 D 差异是否具有总体意义，因为 bootstrap 区间包含零。
- `c_PEATOM` 的来源和物理含义不必在本项目中确认；它只用于测试 SOAP 坐标是否保留辅助标量信息。
- D 与 PEATOM 的关联不能解释为晶界能量规律。
- 原子级 bootstrap 是否高估独立信息，未解决。

## 4. 需要讨论

| 问题 | 主要风险 | 建议处理 |
|---|---|---|
| D 的主距离 | 原始距离混入范数效应 | 重算 `D_norm(k)` 并和当前 D 并行报告 |
| 清洁体相筛选 | 辅助标量筛选引入条件化偏差 | 主分析禁用辅助标量筛选，只作敏感性对照 |
| 参考体制 | 绝对 D 尺度随参考变化 | 固定共同子集，并报告 pooled/per-state 两套 |
| 辅助标量 | PEATOM 只能测试信息保留，不能证明物理能量意义 | 方法探索中保留为描述性目标，不推断物理能量 |
| 统计单位 | 原子被当作独立样本 | 增加构型级汇总和分层 bootstrap |
| 状态差异 | 置信区间包含零 | 不声称 stable/metastable 的无序度排序 |

## 5. 当前处置

- 可以把 `D(k=10)` 作为当前数据集内的描述性连续坐标。
- 不把它称为热力学无序度或能量序参量。
- PEATOM 只作为辅助标量目标，不作为项目必须解决的问题。
- 参考体相是否使用辅助标量筛选仍需做方法敏感性，因为它会影响 D 的定义。
