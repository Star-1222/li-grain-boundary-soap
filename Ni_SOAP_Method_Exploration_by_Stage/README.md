# Ni SOAP 方法探索（按 Stage 整理）

整理日期：2026-09-25

本项目的主要目标是探索可迁移的 SOAP 方法。它不是势函数或能量来源审计，后续工作重点是 SOAP 参数、距离定义、体相参考、LAE 稳定性、方向表示和独立验证。

本目录按 Ni SOAP 六阶段流程归档，每个 Stage 文件夹内含：

- `01_报告/`：覆盖该阶段的方法学报告；
- `02_脚本/`：该阶段使用的 Python 脚本与输入文件；
- `03_输出/`：该阶段生成的数据、图表、XYZ 和报告草稿。

## Stage 目录

- `Stage01_数据准备与SOAP初测/`
- `Stage02_SOAP表示与审计/`：Stage 2 / 2.5 / 2.75
- `Stage03_LAE阈值与LAE_LER构建/`：Stage 3A / 3B
- `Stage04_无序度与能量关联/`：Stage 4A / 4B
- `Stage05_物理空间与方向/`：Stage 5A / 5B
- `Stage06_最终评估/`

## 公共目录

- `00_汇总报告/`：跨 Stage 的完整报告与 proof final / closure
- `05_文献/`：SOAP 原理与 Ni 应用相关文献
- `06_环境与实现/`：环境配置与实现代码

## 文件索引

- `00_汇总报告/项目文件索引_脚本输出报告_按阶段.md`
- `00_汇总报告/项目文件索引_按阶段.csv`

索引列出各阶段脚本、输出文件、报告、重复副本和公共目录文件。完整报告以 `00_汇总报告/` 中的版本为规范入口，Stage 目录下的同名报告为便捷副本。

## 确定性与待讨论报告

- 每个 Stage 的 `01_报告/StageXX_确定性结论与待讨论.md`
- 最终报告：`00_汇总报告/Ni_SOAP_最终报告.md`

这组报告只区分已经由数据或代码确定的内容，以及当前不能确定、需要讨论或补做实验的内容。
