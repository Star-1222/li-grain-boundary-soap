# 第一章　问题意识：这个项目在问什么

**读**：`README.md`（最上面两段）

**要理解的核心**

锂的熔点只有 453.7 K。**室温（约 300 K）相当于它的 0.66 倍熔点。**

这个数字的含义是：真实的锂晶界在室温下**不是**教科书里那种整齐的周期性结构，而是热扰动下持续重构的无序态。

所以项目要回答的是：

> **热重构出来的无序晶界，冷下来之后还能不能存在？**

如果能，那所有基于"理想晶界模型"的预测都站不住脚 —— 这是整个课题的立论根基。

# 第二章　物理对象：你造的到底是什么

**读**：`Lithium_GrainBoundary_Project/Reports/GB_Construction/README_BI.md` 的「物理模型」与「双晶构建」两节

**要理解的核心**

| 概念 | 含义 |
|---|---|
| **BCC 锂** | 体心立方晶体结构 |
| **Σ5** | 重合位置点阵（CSL）的重合度倒数。Σ5 表示每 5 个格点有 1 个重合 |
| **(310) 晶界面** | 两个晶粒的交界面所在的晶面 |
| **[001] 旋转轴** | 两个晶粒绕这个轴相对旋转 |
| **36.87° 取向差** | 由上面的轴和面共同决定的旋转角 |

**为什么盒子里面有两条晶界？**

因为沿晶界法向（x 方向）用了**周期性边界**。原子从盒子一端出去会从另一端进来，于是"一条晶界"在周期意义下变成两条 —— 这不是 bug，是几何必然。计算晶界能时的分母 `2 × Ly × Lz` 里的那个 2 就来自这里。

**关键数字**

```
初始晶格常数   3.506186475312 Å    ← 由体相参考弛豫得到，不是查表来的
超胞           K=6, J=3, L=10
原子数         3720 → 删 120 → 3600
盒子           66.5252 × 33.2626 × 35.0619 Å
最小原子间距   2.217507 Å
```

**为什么是 3600 而不是 3720？**

构建时会在两个晶界面上独立检测**重合位点**，每对重合点删掉一个原子，并且在两个晶粒之间**平均分配**（各删 60 个）。对称删除是为了不偏袒任一晶粒。

**自检**：

1. 盒子里为什么有两条晶界？
2. 从 3720 到 3600 删掉的 120 个原子是怎么定的？
3. 为什么必须用**弛豫后**的晶格常数而不是文献值来搭建？

# 第三章　计算链条：数据是怎么产生的

**读**：`Lithium_GrainBoundary_Project/01_GB_Construction/Sigma5_310_Metastable_GB/v2_production/docs/README.md`，然后翻 `lammps/` 下的 `in.*` 脚本

**要理解的核心**

整条链条是"**先造有序，再打乱，再冻住，再看它稳不稳**"：

```
体相参考 ──► 极小化 ──► 退火 ──► 淬火 ──► 保持
(定晶格常数)  (消残余力)  (造无序)  (冻住无序) (验证亚稳)

in.bulk_energy  in.1_minimize  in.2_anneal  in.3_quench  in.4_final
```

每一步的参数选择都有理由：

| 步骤 | 参数 | 为什么这么选 |
|---|---|---|
| 退火 | 363 K（约 0.8 倍熔点） | 足够诱发重构，又不至于整体熔化 |
| 退火 | 25 ps | 保证重构充分发生 |
| 淬火 | 10 K/ps | 快冷，把无序"冻"下来而不是让它弛豫回去 |
| 保持 | 10 K / 0 bar，5 ps | 检验冻结的无序态是否真的亚稳 |

**产物的三种角色**

| 扩展名 | 是什么 | 能不能重来 |
|---|---|---|
| `.data` | 某一时刻的静态结构快照 | 是链条的节点，不能跳 |
| `.dump` | 多帧轨迹，看过程 | 可重跑，代价是算力 |
| `.restart` | 检查点，含速度场 | **不可再生** —— 必须从上一阶段重跑 |

**自检**：

1. `in.2_anneal` 用的是 NVT 还是 NPT？温度多少？（提示：这跟 2×2 实验不一样，见第五章）
2. 为什么淬火要快（10 K/ps 而不是 1 K/ps）？
3. 如果丢了 `.restart`，能只靠 `.data` 恢复吗？为什么不能？

# 第四章　动手验证：自己把结论算出来

**做**：在 `D:\Research` 下运行

```cmd
python tools\compute_gb_energy.py
```

**要理解的核心**

晶界过剩能的定义：

```
γ_GB = (E_双晶 − N × E_体相每原子) / (2 × Ly × Lz)
```

物理含义：把这个双晶的总能量，扣掉"同样多的原子如果是完美体相会是多少能量"，剩下的就是晶界带来的**额外**能量，再除以晶界面积。

运行结果（3600 原子基准）：

```
理想 CSL 晶界     165.0 mJ/m²
亚稳无序晶界      153.2 mJ/m²
差值              −11.9 mJ/m²
```

**这个负号是整个课题最关键的发现**：无序态能量**更低**，说明理想 CSL 结构并非基态。

同时脚本会打出一列「可比性」标记，这很重要 ——

> 退火末帧是 363 K 的快照，它的势能含**热贡献**（约 709 eV），
> 拿去算晶界能是错的。只有 0 K 弛豫结构才能这么比。

**自检**：

1. 公式里分母为什么是 `2 × Ly × Lz` 而不是 `Ly × Lz`？
2. 为什么"退火末帧"那一行不能用来算晶界能？
3. 两条 0 K 曲线都有约 −670 bar 的残余应力，这对结论有什么影响？

# 第五章　结论是怎么得出的

**读**：

- `Li_Sigma5_310_2x2_阶段一验收_2026-09-05_new/阶段一验收汇报_2026-09-04.md`
- `.../Li_Sigma5_310_2x2_阶段一零压结果_2026-09-03/6_结构分析/cna_phase1_report.txt`

**要理解的核心**

验收不是"看起来对了"，而是**四条可证伪的判据**同时成立：

1. 363 K NPT 退火 ≥ 2 ps
2. 退火后晶界出现真实无序，**同时**晶粒内部保持 BCC
3. 以 10 K/ps 淬火到 10 K
4. 10 K、0 bar 下保持 > 1 ps，无序仍维持

怎么证明"晶界无序而晶粒没熔化"？用 CNA（共近邻分析）统计 BCC 比例：

```
              晶界 BCC    晶粒内部 BCC
初始           73.3%        100.0%
极小化后        60.0%        100.0%
退火末帧        43.7%         99.9%    ← 关键
终态           38.1%         98.7%
```

**晶界掉到 38%，晶粒内部仍有 98.7%** —— 这就是"晶界重构但没整体熔化"的定量证据。同时无序带宽度从 2.5 Å 长到 6.5 Å。

**但结论有边界**（这点最容易忽略）：

> 验收用的"0 bar"是**标量时均压力**（+1.7 bar），
> 而三个应力分量是 −187 / +386 / −196 bar。
> 如果改成要求各分量都趋零，需要补一次 `aniso` NPT 复核。

**自检**：

1. 四个判据分别对应报告里的哪个字母（A–F）？
2. 为什么"能量变平"不能当作成功的证据？（提示：流程里明文禁止这样做）
3. 现在的"验收通过"是在什么口径下成立的？

# 第六章　方法线：SOAP 在做什么

**读**：`Ni_SOAP_Method_Exploration_by_Stage/00_汇总报告/Ni_SOAP_最终报告.md`

**要理解的核心**

**先搞清它不是什么**：不是势函数审计，不是晶界能量来源验证。`c_PEATOM` 只是当"现成的局域标量"用来测试 SOAP 坐标还保不保留信息。

SOAP 的本质：把每个原子周围的局域环境编码成一个高维向量（这里是 1014 维），用来比较"两个原子的局域结构像不像"。

六个阶段，每一阶段的产出是**一条否定或一条边界**：

| 阶段 | 得到了什么 |
|---|---|
| 01 | CFG 能解析，SOAP 能算（矩阵 4659 × 1014） |
| 02 | 距离的数学关系厘清：`d_norm² = 2 − 2·K_cos`；发现**原始距离里 42–46% 来自范数差，不是形状差异** |
| 03 | 贪心 LAE 有顺序依赖、epsilon 邻域图完全连通 → **离散分类不可用** |
| 04 | D 数值稳健，但含义依赖距离与参考 → 只作描述性坐标 |
| 05 | 方向混入范数效应，PCA 在全量数据上拟合 = 泄漏 |
| 06 | 控制物理描述符后，相关系数 **0.83 → 0.21** |

**为什么这一章重要**：因为方法线的结论是"**这把标尺还没校准好**"（参数未冻结、距离未定义、离散分类不可用），而物理线已经在用它描述锂晶界了。**顺序反了** —— 详见 `PROJECT_REVIEW.md` 第三部分。

**自检**：

1. `d_raw` 和 `d_norm` 的区别是什么？为什么原始距离"不纯"？
2. 为什么贪心 LAE 不能用作物理分类？
3. 六阶段的最终结论，对"SOAP 有用吗"这个问题怎么回答？

# 第七章　当前未决问题：接下来做什么

**读**：`PROJECT_REVIEW.md`（全部）

**要理解的核心**

按"能不能马上做"分三档：

| 优先级 | 事项 | 为什么先做它 |
|---|---|---|
| 1 | 核实 D 与位移范数相关 0.99998 | 决定方法线是否成立 |
| 2 | 用一致协议重算 γ_GB | 课题最核心的物理量 |

还有两个**结构性**问题需要决策：

- **热协议不一致**：3600 原子基准用 300 K + NVT，14400 原子验收用 363 K + NPT。同时变了两个变量，结果差异无法归因
- **单条轨迹无统计**：种子全局固定 12345，所有运行是同一条轨迹。"亚稳"的主张需要多组种子复现
